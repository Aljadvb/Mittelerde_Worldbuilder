# Schriften der App

Die App enthält freie Schriften unter der SIL Open Font License 1.1 (Lizenztexte in diesem Ordner):

- **Uncial Antiqua** (Titel, Überschriften, Knöpfe) – © Astigmatic, OFL-UncialAntiqua.txt
- **EB Garamond** (Fließtext) – © The EB Garamond Project Authors, OFL-EBGaramond.txt
- **Alcarin Tengwar** (elbische Inschriften) – © Toshi Omagari, Reserved Font Name „Alcarin“, OFL-AlcarinTengwar.txt.
  Unverändert eingebunden (`app/src/main/res/font/alcarin_tengwar.ttf`, `editor/src/main/resources/fonts/`).

Uncial Antiqua und EB Garamond sind feste Schnitte der Google-Fonts-Dateien, auf lateinische Zeichen verkleinert.

Optional kann der private Material-Katalog eine eigene Titelschrift (`"titleFont"`) und eine Bilderschrift für
Verzierungen (`"ornamentFont"`) mitbringen. Solche Dateien werden nicht im Repository abgelegt.
