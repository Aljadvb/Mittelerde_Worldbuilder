# Schriften der App

Die App enthält freie Schriften unter der SIL Open Font License 1.1 (Lizenztexte in diesem Ordner):

- **EB Garamond** (Fließtext) – © The EB Garamond Project Authors, OFL-EBGaramond.txt
- **Cinzel** (Ersatzschrift für Titel) – © The Cinzel Project Authors, OFL-Cinzel.txt

Die Dateien unter `app/src/main/res/font/` sind feste Schnitte (400, 600, kursiv; Cinzel 700) der variablen
Google-Fonts-Dateien, auf lateinische Zeichen verkleinert.

Eine eigene Titelschrift kann im privaten Material-Katalog mitgeliefert werden (`"titleFont": "schrift/titel.ttf"`).
Sie wird nicht im Repository abgelegt.
